# 中国象棋游戏

这是一个使用Java Swing开发的中国象棋游戏，适合初学者学习Java GUI编程和游戏开发。

## 项目结构

```
src/
├── Main.java          # 主类，包含游戏状态变量和主入口
├── Env.java           # 环境配置类（数据库连接信息）
├── GameFrame.java     # 游戏界面类
├── GameLogic.java     # 游戏逻辑处理类
├── GameLoop.java      # 游戏循环控制类
├── Gaming.java        # 游戏主流程控制类
├── Login.java         # 用户登录界面
├── Database.java      # 数据库操作类
├── Gamesave.java      # 游戏存档类
├── xy.java            # 坐标类
└── Pieces/
    └── Piece.java     # 棋子基类（抽象类）
```

## 主要功能

1. **用户登录系统** - 支持用户注册和登录
2. **游戏存档** - 自动保存和加载游戏进度
3. **完整的象棋规则** - 支持所有象棋棋子的标准走法
4. **图形界面** - 美观的棋盘和棋子显示
5. **回合制游戏** - 红黑双方轮流走棋

## 棋子编码说明

棋子使用数字编码：
- **红方棋子（奇数）**: 11(车), 13(兵), 15(帅), 17(马), 19(相), 21(炮), 23(士)
- **黑方棋子（偶数）**: 10(车), 12(兵), 14(将), 16(马), 18(相), 20(炮), 22(士)

## 运行方法

1. 确保已安装Java开发环境（JDK 8或更高版本）
2. 配置数据库连接信息（在Env.java中）
3. 运行Main类的main方法

## 学习要点

这个项目涵盖了以下Java编程知识点：

1. **面向对象编程** - 类的设计和封装
2. **GUI编程** - Swing组件的使用
3. **多线程编程** - 界面和逻辑的分离
4. **数据库操作** - JDBC连接和CRUD操作
5. **游戏逻辑** - 状态机和规则判断

## 适合人群

- Java初学者想要学习GUI编程
- 对游戏开发感兴趣的学习者
- 想要了解象棋规则实现的学生

## 注意事项

- 项目需要MySQL数据库支持
- 确保数据库驱动已正确配置
- 游戏资源文件位于content目录下
